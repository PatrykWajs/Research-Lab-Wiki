# Research Lab Wiki

Αυτοκατευθυνόμενες, πλήρως-τεκμηριωμένες έρευνες — κάθε μία ανιχνεύεται σε μελέτες με κριτική αξιολόγηση και επίσημες πηγές, ζυγισμένες ειλικρινά, και κλείνουν με εκτίμηση με βαθμολογία αποδεικτικών στοιχείων.

-   :material-flask-outline:{ .lg .middle } __BPA στις Θερμικές Αποδείξεις & Ανθρώπινη Υγεία__

    ---

    Πώς η δισφαινόλη Α από αποδείξεις ταμειακών και καρτών εισέρχεται στο σώμα, τι κάνει, και πόσο πραγματικός είναι ο κίνδυνος — για τον μέσο άνθρωπο έναντι των ταμείων. **29 τεκμηριωμένες μελέτες**, με βαθμολογία αποδεικτικών στοιχείων.

    [:octicons-arrow-right-24: Read the research](bpa-thermikes-apodeixeis.md)

-   :material-bone:{ .lg .middle } __Κολλαγόνο: Τι Πραγματικά Κάνει έναντι Τι Πιστεύουν οι Άνθρωποι__

    ---

    Ύπνος, έντερο, δέρμα, αρθρώσεις, οστά, μυς — ποιες αξιώσεις για το κολλαγόνο είναι πραγματικές, και ποιες είναι απλώς ένα αποτέλεσμα γλυκίνης. **74 τεκμηριωμένες μελέτες**, με σημαία χρηματοδότησης.

    [:octicons-arrow-right-24: Read the research](kollagono.md)

-   :material-arm-flex:{ .lg .middle } __Τεστοστερόνη: Τι Πραγματικά Αυξάνει έναντι Τι Πιστεύουν οι Άνθρωποι__

    ---

    Διατροφή, ύπνος, συμπληρώματα, no-fap, έλαια σπόρων, ήλιος, πλαστικά — ποιες αξιώσεις "αυξάνουν φυσικά την τεστοστερόνη" ισχύουν, και ποιες (σόγια, ρόδι, no-fap, ήλιος-στους-όρχεις) είναι μύθοι. **96 τεκμηριωμένες μελέτες**, με βαθμολογία αποδεικτικών στοιχείων.

    [:octicons-arrow-right-24: Read the research](testosteroni.md)

-   :material-bottle-tonic-outline:{ .lg .middle } __Έλαια Σπόρων: Τι Πραγματικά Κάνουν έναντι Τι Πιστεύουν οι Άνθρωποι__

    ---

    Φλεγμονή, καρδιακή νόσος, παχυσαρκία, "τοξικό" λάδι τηγανίσματος — ποιες αξιώσεις "τα έλαια σπόρων είναι δηλητήριο" ισχύουν, και ποιες (ο μηχανισμός φλεγμονής, "προκαλούν καρκίνο," "αντικατάσταση με λίπος") είναι μύθοι ή μάρκετινγκ. **96 τεκμηριωμένες πηγές**, όλες οι PMID επαληθευμένες.

    [:octicons-arrow-right-24: Read the research](sporelaia.md)

-   :material-dumbbell:{ .lg .middle } __Κρεατίνη: Τι Πραγματικά Κάνει έναντι Τι Πιστεύουν οι Άνθρωποι__

    ---

    Βλάβη νεφρών, απώλεια μαλλιών, "είναι στεροειδές," φούσκωμα, πρέπει-να-κυκλώνεται — ποιες φόβοι για την κρεατίνη ισχύουν (σχεδόν κανένας), και τι πραγματικά κάνει για τους μυς, τον εγκέφαλο και την υγεία. Το πιο μελετημένο, καλύτερα τεκμηριωμένο, ασφαλέστερο αθλητικό συμπλήρωμα. **169 τεκμηριωμένες πηγές**, όλες οι PMID επαληθευμένες.

    [:octicons-arrow-right-24: Read the research](kreatini.md)

-   :material-fish:{ .lg .middle } __Ωμέγα-3 / Ιχθυέλαιο: Τι Πραγματικά Κάνει έναντι Τι Πιστεύουν οι Άνθρωποι__

    ---

    Καρδιά, εγκέφαλος, αρθρώσεις, διάθεση, "εξυπνότερο μωρό," τεστοστερόνη — ποιες αξιώσεις για το ιχθυέλαιο ισχύουν, και ποιες είναι μάρκετινγκ. Το αίμα ωμέγα-3 προβλέπει τη θνησιμότητα, ωστόσο τα συμπληρώματα είναι άκυρα για την πρωτογενή πρόληψη και αυξάνουν την κολπική μαρμαρυγή σε υψηλή δόση. **146 τεκμηριωμένες πηγές**, όλες οι μελέτες PMID αντιστοιχισμένες με τίτλο.

    [:octicons-arrow-right-24: Read the research](omega-3-ichthelaio.md)

-   :material-white-balance-sunny:{ .lg .middle } __Βιταμίνη D: Τι Πραγματικά Κάνει έναντι Τι Πιστεύουν οι Άνθρωποι__

    ---

    Οστά, ανοσία, διάθεση, τεστοστερόνη, καρκίνος, μακροζωία — ποιες αξιώσεις για τη βιταμίνη D είναι πραγματικές, και ποιες ("όλοι έχουν έλλειψη, μεγαδόση για ασφάλεια") είναι ένα τεχνητό όριο; Μια θεραπεία έλλειψης που πωλείται λανθασμένα ως ενισχυτικό: άκυρη για σχεδόν κάθε σκληρό αποτέλεσμα στους πλήρεις, πραγματική μόνο για τη διόρθωση της έλλειψης. **90 τεκμηριωμένες πηγές**, όλες οι PMID επαληθευμένες.

    [:octicons-arrow-right-24: Read the research](vitamini-d.md)

-   :material-atom:{ .lg .middle } __Μαγνήσιο: Τι Πραγματικά Κάνει έναντι Τι Πιστεύουν οι Άνθρωποι__

    ---

    Ύπνος, κράμπες, η μορφή "γλυκινικό", τεστοστερόνη, "όλοι έχουν έλλειψη" — ποιες αξιώσεις για το μαγνήσιο είναι πραγματικές; Ένα απαραίτητο μεταλλικό στοιχείο με ένα πραγματικό διατροφικό κενό, όπου σχεδόν κάθε όφελος είναι διόρθωση έλλειψης και η ισχυρότερη απόδειξη είναι η ενδοφλέβια νοσοκομειακή ιατρική, όχι το συμπλήρωμα. **151 τεκμηριωμένες πηγές**, όλες οι PMID επαληθευμένες.

    [:octicons-arrow-right-24: Read the research](magnisio.md)

-   :material-medication-outline:{ .lg .middle } __Ψευδάργυρος: Τι Πραγματικά Κάνει έναντι Τι Πιστεύουν οι Άνθρωποι__

    ---
